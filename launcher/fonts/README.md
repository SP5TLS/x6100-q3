# Font

`10x20.bdf` is a subset of the X11 "misc-fixed" 10x20 font
(`-Misc-Fixed-Medium-R-Normal--20-200-75-75-C-100-ISO10646-1`, Markus
Kuhn's ucs-fonts release 1.91), as distributed by X.Org in
`font-misc-misc-1.1.3.tar.xz`
(<https://www.x.org/releases/individual/font/>, SHA-256
`79abe361f58bb21ade9f565898e486300ce1cc621d5285bec26e14b6a8618fed`).

Its licence, from the font's `COPYRIGHT` property and the package's
`COPYING` file:

> Public domain font. Share and enjoy.

The subset keeps the glyphs x6100-launcher can be asked to show (Wi-Fi
and Bluetooth names, menu text): U+0020–U+007E, U+00A0–U+024F (Latin),
U+0370–U+03FF (Greek), U+0400–U+04FF (Cyrillic), general punctuation,
U+20AC, arrows, box drawing, blocks, geometric shapes, miscellaneous
symbols, U+2713–U+2718 and U+FFFD. Glyphs are unchanged; only the
`CHARS` count and one `COMMENT` line differ from the original header.
