Game data

The game files are not part of this system: use your own copy of Quake III Arena. baseq3/pak0.pk3 comes from the game; pak1.pk3 to pak8.pk3 from the free 1.32 point release (ioquake3.org/extras/patch-data, unzip it first). Team Arena also needs missionpack/pak0.pk3 to pak3.pk3.

Choose your game's folder (the one with baseq3 in it) and every .pk3 and .cfg in it is sent, each into the folder of the same name on the radio. Loose files go into the folder chosen here.
